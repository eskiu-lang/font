## `<font>`

glyph atlases.


## `<font/raster>`

Glyph outlines to antialiased coverage bitmaps.

```eskiu
GlyphBitmap b = f.render(f.glyph('g'), 32.0)?;
defer b.free();
// b.pixels: b.width * b.height coverage values (0 to 255), top row
// first; b.left and b.top place it from the pen position on the
// baseline (top is negative above the baseline).

```

The coverage is exact area coverage: every outline segment adds the signed
area it covers to each pixel of its rows, and a running sum along each row
gives the coverage (the method of font-rs). Curves are flattened finely
enough that the error stays under a tenth of a pixel.

### GlyphBitmap

```eskiu
struct GlyphBitmap {
    int width;
    int height;
    int left;
    int top;
    *uint8 pixels;
}
```

A glyph's 8-bit coverage bitmap, width x height bytes (0 empty, 255 covered), top row
first. left and top place it: its top-left pixel is left pixels right of the pen and top
pixels above the baseline.

### GlyphBitmap_free

```eskiu
void GlyphBitmap_free(*GlyphBitmap self)
```

Frees the pixels.

### font_rasterize

```eskiu
Result<GlyphBitmap, string> font_rasterize(List<FontCurve>* curves, float scale, float dx)
```

Renders curves (font units, y up) at scale pixels per unit, shifted right
by dx pixels (a subpixel pen position from 0 to 1).

### Font_render

```eskiu
Result<GlyphBitmap, string> Font_render(*Font self, int g, float px)
```

Glyph g at a font size of px pixels.

### Font_render_at

```eskiu
Result<GlyphBitmap, string> Font_render_at(*Font self, int g, float px, float dx)
```

Glyph g at px pixels with the pen dx pixels (0 to 1) right of a pixel
boundary.


## `<font/text>`

Laying out and drawing text, and glyph atlases for GPU text.

```eskiu
List<FontPlaced> line;
f.layout("Hello, Eskiu", 24.0, &line);   // pen positions with kerning
f.draw("Hello", 24.0, rgba, width, height, 10, 40, 0xFFFFFFFF);

FontAtlas atlas = f.atlas(32.0, " !\"#...~")?;  // one 8-bit texture
FontAtlasGlyph* g = atlas.find('A');            // its rectangle and metrics

```

Text is UTF-8; '\n' starts a new line. Positions are in pixels from the
first line's baseline, y down.

### FontPlaced

```eskiu
struct FontPlaced {
    uint32 cp;
    int glyph;
    float x;
    float y;
}
```

One glyph placed by Font_layout: its character, glyph index and pen position (x, y) in
pixels.

### FontAtlasGlyph

```eskiu
struct FontAtlasGlyph {
    uint32 cp;
    int glyph;
    int x;
    int y;
    int width;
    int height;
    int left;
    int top;
    float advance;
}
```

Where a glyph is in a FontAtlas: its character and glyph index, its rectangle in the
texture (x, y, width, height), how to place it from the pen (left, top, as in
GlyphBitmap) and its advance in pixels.

### FontAtlas

```eskiu
struct FontAtlas {
    int width;
    int height;
    *uint8 pixels;
    float size;
    float line_height;
    float ascent;
    List<FontAtlasGlyph> glyphs;
}
```

An 8-bit coverage texture of width x height holding the glyphs.

### font_utf8_next

```eskiu
uint32 font_utf8_next(string s, *int64 i)
```

Decodes the UTF-8 character at s[*i] and moves *i past it; a malformed
sequence gives U+FFFD and moves one byte.

### Font_line_height

```eskiu
float Font_line_height(*Font self, float px)
```

The distance from one baseline to the next at px pixels.

### Font_layout

```eskiu
void Font_layout(*Font self, string text, float px, List<FontPlaced>* out)
```

Appends each character of text with its pen position.

### Font_measure

```eskiu
void Font_measure(*Font self, string text, float px, *float width, *float height)
```

The width of the widest line of text, and its height (lines times the line
height), at px pixels.

### Font_draw

```eskiu
void Font_draw(*Font self, string text, float px, *uint8 rgba, int width, int height, float x, float y, uint32 color)
```

Draws text into an RGBA image (width x height pixels, 4 bytes each) with the
first baseline at (x, y), blending color (0xRRGGBBAA) by each pixel's
coverage.

### Font_atlas

```eskiu
Result<FontAtlas, string> Font_atlas(*Font self, float px, string chars)
```

Renders every character of chars (UTF-8) at px pixels into one atlas,
packed in rows with a pixel of space around each glyph.

### FontAtlas_find

```eskiu
FontAtlasGlyph* FontAtlas_find(*FontAtlas self, uint32 cp)
```

The atlas entry of character cp, or null when the atlas does not have it.

### FontAtlas_free

```eskiu
void FontAtlas_free(*FontAtlas self)
```

Frees the texture pixels and the glyph list.


## `<font/ttf>`

TrueType fonts: character mapping, metrics, kerning and glyph
outlines.

```eskiu
Font f = font_load("DejaVuSans.ttf")?;
defer f.free();
int g = f.glyph('A');
float scale = f.scale(32.0);           // font units to pixels at 32 px
float advance = (float)f.advance(g) * scale;

```

The font is read from the 'cmap' (formats 4 and 12), 'head', 'hhea',
'hmtx', 'maxp', 'loca', 'glyf' and 'kern' tables. Glyphs are quadratic
outlines (TrueType); composite glyphs are flattened into their parts.
OpenType fonts with CFF outlines are not supported.

### Font

```eskiu
struct Font {
    *uint8 data;
    uint64 len;
    uint32 cmap;
    int cmap_format;
    uint32 loca;
    uint32 glyf;
    uint32 glyf_len;
    uint32 hmtx;
    uint32 kern;
    int num_glyphs;
    int num_hmetrics;
    int units_per_em;
    bool loca_long;
    int ascent;
    int descent;
    int line_gap;
}
```

A TrueType font held in memory, with the offsets of the tables it reads and its metrics
in font units: units_per_em, ascent, descent (negative, below the baseline) and
line_gap. Make one with font_load or font_parse.

### FontCurve

```eskiu
struct FontCurve {
    float x0;
    float y0;
    float cx;
    float cy;
    float x1;
    float y1;
}
```

One quadratic segment of an outline, in font units (y up); a straight
line has its control point at its middle.

### FontBox

```eskiu
struct FontBox {
    int x0;
    int y0;
    int x1;
    int y1;
}
```

A glyph's bounding box in font units, y up: (x0, y0) bottom-left, (x1, y1) top-right.

### font_load

```eskiu
Result<Font, string> font_load(string path)
```

Reads the TrueType (.ttf) file at path.

### font_parse

```eskiu
Result<Font, string> font_parse(*uint8 data, uint64 len)
```

Parses a font held in memory. On success the Font owns data (Font_free
frees it); on an error data stays the caller's.

### Font_free

```eskiu
void Font_free(*Font self)
```

Frees the font's data.

### Font_scale

```eskiu
float Font_scale(*Font self, float px)
```

Pixels per font unit for a font size of px pixels (the em square).

### Font_glyph

```eskiu
int Font_glyph(*Font self, uint32 cp)
```

The glyph index of a Unicode code point; 0 (the missing glyph) when the
font has none.

### Font_advance

```eskiu
int Font_advance(*Font self, int g)
```

The advance width of glyph g, in font units.

### Font_left_bearing

```eskiu
int Font_left_bearing(*Font self, int g)
```

Glyph g's left side bearing, in font units: from the pen to the left of its outline.

### Font_kerning

```eskiu
int Font_kerning(*Font self, int a, int b)
```

The kerning between glyphs a and b, in font units (from the 'kern' table,
format 0); 0 when the font has none.

### Font_box

```eskiu
FontBox Font_box(*Font self, int g)
```

The glyph's bounding box in font units (all zero for an empty glyph).

### Font_outline

```eskiu
bool Font_outline(*Font self, int g, List<FontCurve>* out)
```

Appends glyph g's outline (font units, y up) to out; false when the glyph
data is malformed (out then holds what was read before the error).
